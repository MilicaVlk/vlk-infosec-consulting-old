Cookies & Website Technologies

Information about website storage, security checks and external links.

Last reviewed: 21 September 2026

Website assets and form entries

The website’s own static code does not set cookies or use localStorage or sessionStorage. It does not include analytics tags, advertising pixels, embedded social feeds or a chatbot. Images and fonts are served as site assets. Form entries are held in the current page while you complete the enquiry.

Security services

When online submission is enabled, requesting an email code loads Cloudflare Turnstile. Turnstile uses technical signals to help identify automated abuse. Cloudflare hosting and security settings can independently affect request logging or browser storage.

Requesting an email code loads Cloudflare Turnstile, which processes technical signals to help identify automated abuse. Cloudflare hosting and security services may also process request information. See the Cloudflare Turnstile Privacy Addendum for details. Turnstile Privacy Addendum

Optional tracking

No optional tracking is included in this build. Before adding any, VLK InfoSec Consulting must assess the applicable requirements and implement consent controls where required, including an effective refusal and withdrawal route.

Browser controls and external links

You can inspect and clear stored website data through your browser settings. Blocking security services may prevent online submission. LinkedIn links are ordinary outbound links; LinkedIn’s terms apply after navigation.

LinkedIn links lead to external services. Their privacy terms apply after navigation. See the Privacy Notice for personal-data processing.
